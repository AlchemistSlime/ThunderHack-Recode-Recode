# ThunderHack Recode Recode (1.21.4)

**ThunderHack Recode Recode** is an unofficial, community-driven continuation of the legendary ThunderHack Recode client. This project is a complete port of the original client to the newest versions of Minecraft.

## ✨ Features
*   **Minecraft 1.21.4 Support:** Fully updated to work with the latest game versions and rendering pipeline.
*   **Dynamic Custom GUI:** A completely redesigned, sleek dark-themed UI with dynamic accent colors (changes based on your client color settings).
*   **Crystal & Sword HvH Focused:** Retains the core PvP modules that made the original client famous.
*   **Custom Main Menu & Settings:** Integrated custom menus for a seamless experience.

## 📦 Installation
1.  Install **Fabric Loader** for Minecraft **1.21.4**.
2.  Download **Fabric API** and place it in your `mods` folder.
3.  Ensure you have **Java 21+** installed.
4.  Download the latest `ThunderHack-Recode-Recode.jar` from the [Releases](https://github.com/AlchemistSlime/ThunderHack-Recode-Recode/releases) page.
5.  Drop the `.jar` file into your `.minecraft/mods` folder and launch the game.

## 🎮 Usage
*   **ClickGUI:** Press `P` (or check your keybinds) to open the main menu.
*   **Commands:** Use the prefix `@` in chat to execute client commands (e.g., `@bind`).
*   **Module Binding:** Middle-click a module in the ClickGUI to bind it to a key.

# ThunderHack Recode Recode (Русская версия)

**ThunderHack Recode Recode** — это неофициальное продолжение легендарного чит-клиента ThunderHack Recode. Проект представляет собой полный перенос оригинального клиента на актуальные версии Minecraft.

## ✨ Особенности
*   **Поддержка Minecraft 1.21.4:** Полностью адаптирован под новый рендер игры.
*   **Кастомный GUI:** Полностью переработанный интерфейс в темных тонах с поддержкой динамического изменения цвета (акцентный цвет меняется в настройках клиента).
*   **Фокус на HvH:** Сохранены все основные модули для Crystal и Sword HvH, за которые так любили оригинал.
*   **Свое главное меню:** Интегрированные экраны настроек и меню для полного погружения.

## 📦 Установка
1.  Установите **Fabric Loader** для Minecraft **1.21.4**.
2.  Скачайте **Fabric API** и поместите в папку `mods`.
3.  Убедитесь, что у вас установлена **Java 21+**.
4.  Скачайте последнюю версию `.jar` файла со страницы [Releases](https://github.com/AlchemistSlime/ThunderHack-Recode-Recode/releases).
5.  Поместите файл в папку `.minecraft/mods` и запустите игру.

## 🎮 Использование

*   **Привязка модулей:** Нажмите среднюю кнопку мыши (колесико) на модуле, чтобы забиндить его.
