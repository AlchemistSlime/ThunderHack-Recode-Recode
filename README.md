# ThunderHack Recode Recode

**ThunderHack Recode Recode** is an unofficial, heavily modified continuation of the ThunderHack Recode client. Unlike simple ports, this project features an **almost completely rewritten codebase** adapted for modern Minecraft versions. It introduces new features, an overhauled user interface, and drops legacy systems that are no longer functional.

## ✨ Features
*   **Almost Completely Rewritten:** The core code has been rebuilt from the ground up to support modern Minecraft versions (1.21.4 and above) and the latest rendering pipeline.
*   **New Innovations & Cleanup:** Added new features and functionality while removing outdated/broken legacy systems.
*   **Dynamic Custom GUI:** A completely redesigned, sleek dark-themed UI. The accent colors are dynamic and can be customized directly in the client settings.
*   **Crystal & Sword HvH Focused:** Retains and improves the core PvP modules and combat mechanics that made the original client famous.
*   **Custom Main Menu & Settings:** Integrated custom menus for a seamless and unique experience.

## 📦 Installation
1.  Install **Fabric Loader** for your desired Minecraft version.
2.  Download **Fabric API**. *(Important: You must download the exact version of Fabric API that matches your Minecraft version).*
3.  Ensure you have the correct **Java version** installed (Java 21+ is required for 1.21+).
4.  Download the latest `ThunderHack-Recode-Recode.jar` from the [Releases](https://github.com/AlchemistSlime/ThunderHack-Recode-Recode/releases) page.
5.  Drop the `.jar` file and the Fabric API `.jar` into your `.minecraft/mods` folder.
6.  Launch the game with the Fabric profile.

## 🎮 Usage
*   **ClickGUI:** Press `P` (or check your keybinds) to open the main menu.
*   **Commands:** Use the prefix `@` in chat to execute client commands (e.g., `@bind`).
*   **Module Binding:** Middle-click a module in the ClickGUI to bind it to a key.
